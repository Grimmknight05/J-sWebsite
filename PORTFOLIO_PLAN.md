# Portfolio Plan of Action

## 1. Site structure
- Main homepage with navigation to:
  - Coding
  - Video / Documentary
  - Photography
  - 3D
  - Music
- Each subject gets a separate page with its own theme.

## 2. Coding section
- Landing page with:
  - GitHub repo cards for each project
  - short showcase descriptions
  - live/demo links or repo links
- Planned project entries:
  - Space game (Unity play / demo link)
  - Website project
  - CivicZip project
  - SQ3R / PDF viewer project
- Add a `Dev log` subsection:
  - brief progress updates
  - development notes or timeline entries

## 3. Video / Documentary section
- Page for film/video content
- Embed trailers and clips with:
  - Vimeo or YouTube
- Organize into:
  - documentary highlights
  - trailer / clips
  - other video projects
- Use a dark cinematic layout as the base theme

## 4. Photography section
- Gallery landing page
- Organize into themed collections:
  - Tokyo in black & white
  - Nature
- Each collection can be a subsection or mini-page
- Keep the style noir / film-like and raw Y2K

## 5. 3D section
- Decide between:
  - Sketchfab embeds for fast results
  - Three.js custom viewer for full control later
- Create a scrolling page with categories and descriptions
- Structure around:
  - model previews
  - category text
  - short notes about each piece
- Use a sci-fi Y2K theme for the base look

## 6. Music section
- Page with Bandcamp embeds
- Organize by:
  - albums or collections
  - commentary and lyrics / notes
- Keep the theme bright and game-like (Guitar Hero-inspired)

## 7. Theming and styling
- Each section gets its own simple Y2K theme:
  - Coding: space / cyber style
  - Video: dark cinematic
  - Photography: noir film
  - 3D: sci-fi futuristic
  - Music: arcade / guitar hero
- Keep CSS simple and raw so media and GIFs can be added later

## 8. Implementation steps
1. Create page templates for each section
2. Add navigation links on the homepage
3. Build the Coding page with project cards and dev log
4. Build the Video page with embed placeholders
5. Build the Photography page with collection sections
6. Build the 3D page with category blocks and embed/viewer placeholder
7. Build the Music page with Bandcamp embed slots
8. Test navigation and responsive layout

## 9. Future enhancements
- Add project thumbnails, live demos, and GitHub repo badges
- Replace video placeholders with real Vimeo or YouTube embeds
- Add photography galleries and themed mini-pages
- Implement Sketchfab or Three.js viewers for 3D
- Add audio players and Bandcamp sections with lyrics
- Refine each page’s Y2K look with GIFs, textures, and small animations
